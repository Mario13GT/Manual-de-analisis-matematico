# Manual-de-analisis-matematico
Manual avanzado de análisis matemático y ecuaciones diferenciales para ingeniería. Contiene teoría, demostraciones, ejemplos resueltos y ejercicios sobre análisis funcional, EDO y EDP, Fourier, espacios de Sobolev, cálculo de variaciones y métodos numéricos, incluyendo Galerkin y elementos finitos.
